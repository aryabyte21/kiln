# Cursor Agents for CS5224

Specialized agents to keep planning and implementation quality high from day one.

## Agents

- `cto.md`: architecture and sequencing decisions
- `frontend-principal.md`: Next.js, shadcn/ui, accessibility, DX
- `backend-principal.md`: API design, contracts, data boundaries
- `sre-principal.md`: reliability, observability, CI/CD, deployment
- `test-principal.md`: test strategy and quality gates

## Suggested usage

1. Start with `cto.md` for major feature planning.
2. Route implementation to frontend/backend principals.
3. Run review with test + SRE principals before merge.
